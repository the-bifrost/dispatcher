
# Scripts de Desenvolvimento

- `docker.sh`: Faz a instalação oficial do docker e adiciona o usuário ao grupo docker. Executar `sudo ./install-docker.sh`.
- `setup_python_env.sh`: Cria _(instala se necessário)_ um ambiente virtual do python no projeto. Executar `sudo ./setup_python_env.sh`.
- `setup_serial_test_ports.sh`: Cria _(instala se necessário)_ um pseudo-terminal sem eco. Executar `sudo ./setup_serial_test_ports.sh`.
